# Simple Linear Regression from Scratch

A lightweight, clean educational Python library implementing **Simple Linear Regression** optimized via **Gradient Descent** using pure NumPy. Built from the ground up for educational purposes and custom math transparency.

---

## Installation

You can install this library directly from GitHub using `pip`:

```bash
pip install git+[https://github.com/YOUR_USERNAME/simple_linear_regression.git](https://github.com/YOUR_USERNAME/simple_linear_regression.git)
